# 技术栈学习笔记

记录某个技术栈的系统学习过程：学习路线、核心概念、原理拆解与踩坑总结。按类目分目录、每篇一个 Markdown 文件，front-matter 维护元数据。

> 本 README 的「目录索引」部分由脚本自动生成，请勿手改标记之间的内容。

## 目录约定

| 类目 | 目录 |
| --- | --- |
| 基础 | `basics/` |
| 进阶 | `advanced/` |

- 文件命名：`序号-名称slug.md`，如 `001-roadmap.md`
- 新增笔记：复制 `template/note.md`，填写 front-matter 与正文
- front-matter 字段：`id`（序号）、`title`、`difficulty`（easy/medium/hard）、`tags`、`date`、`juejin`（掘金文章链接）
- 类目可按实际技术栈自由增删（新建目录即可，索引脚本自动扫描）

## 更新目录索引
